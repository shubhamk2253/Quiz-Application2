# QuizQuest — Quiz Application (Feature Set C)

## Problem Statement
Build a quiz application that allows users to select a category and difficulty, answers randomly selected questions, calculates a score, reviews correct answers, and views a final result.

## Assigned Feature Set
**Problem 4 — Quiz Application, Feature Set C**
- Category and difficulty selection
- Random questions
- Score calculation
- Correct-answer review
- Final result

## Features Implemented
- Choose from Python, General Knowledge, and Science.
- Choose Easy, Medium, Hard, or All Difficulties.
- Randomly selects 10 questions for each quiz.
- Scores one point for each correct answer.
- Shows the score, percentage, performance message, and answer explanations.
- Allows the user to play again or change settings.

## Instructions to Run the Project
1. Install Python 3.10 or newer.
2. Open a terminal in the project folder.
3. Install the dependency:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the app:
   ```bash
   streamlit run app.py
   ```
5. The application opens in your browser.
